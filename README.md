# Engram · 织忆

> 每段经历都是一道会被重新点亮的刻痕，从切片到系列，编织出一部完整的历史。

SillyTavern 长程记忆插件（开发中，尚未发布）。

## 安装

SillyTavern → Extensions → Install Extension，粘贴本仓库地址：

```
https://github.com/addict-19/Engram
```

## 状态

🚧 早期开发中，接口与数据格式随时可能变化，暂不建议日常使用。
